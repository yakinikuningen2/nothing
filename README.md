# 何もありません。

真っ暗な場所で、隠された54個の実績を見つけるPC・スマートフォン向けブラウザゲームです。マウスとキーボード、またはタッチで遊べます。ゲームオーバーも時間制限もありません。HTML / CSS / JavaScriptだけで動作し、外部ライブラリ・外部フォント・画像配信・バックエンドは不要です。

## 起動

このフォルダーの `index.html` または `dist/index.html` をブラウザで開くと遊べます。保存とコピーの動作を安定させるには、Node.js 18以上でローカルサーバーを使ってください。

```sh
cd 真っ暗
node server.cjs
```

ブラウザで **http://127.0.0.1:4173/** を開きます。依存パッケージのインストールは不要です。配信する場合は `dist/` の内容を静的ホスティングへ配置してください。検証用サーバーはPC自身からのみ接続できます。

`file:` と `http:`、別のブラウザ、別のホストでは保存領域が別です。プライベートブラウズやストレージ制限環境では進捗が残らない場合があります。保存に失敗してもその場でプレイは続行できます。

## 遊び方（軽いヒント）

[公開版](https://nanimoi-arimasen-yakin.mixedflea64.chatgpt.site) もPCのブラウザで遊べます。本人限定のため、同じアカウントでのログインが必要な場合があります。

- 暗闇を押す、待つ、線を描く、キーを押すなど、思いつく操作を試してください。
- 通常画面は中央のタイトルと操作アイコンだけです。実績・結果・設定は下部のアイコンから開き、実績数や達成方法はメニュー内で確認します。アイコンにマウスを置くと名前が表示されます。
- 左下の点はかすかに見える暗さです。触れる場所によってカーソルの種類は変わりません。
- タイトルの文字をドラッグで選択した後は、別の場所をクリックすると解除されます。「だいたい、真ん中」はタイトルをクリックすれば達成でき、タイトル周辺も判定に含みます。
- 実績解除の通知には「長押しする」「ドラッグする」程度の短い条件を表示します。秒数・距離・回数などの具体的な判定値は出しません。
- 現在は開発モードです。「実績」一覧で、未解除を含むすべての実績名と達成方法を確認できます。必要な操作やキーの順番も明記しています。方法を読むだけで実績が自動解除されることはありません。
- 設定は「動きを減らす」「通知をもう一度見る」「最初からやり直す」の3項目だけです。
- 通知も触れます。逃した通知は実績一覧の「通知を再表示」または設定の「通知をもう一度見る」で出し直せます。通知が消えても、解除済みの実績カードを一覧でドラッグすればドラッグ実績を達成できます。
- 実績数によって暗闇の文字・色・仕掛けは変化しません。すべて解除しても別画面へ自動移動しません。
- 「結果」から投稿用テキストをコピーしたり、Xの投稿画面を開けます。投稿はプレイヤー自身が行います。自動投稿はしません。

スマートフォンでは実績一覧の「キー操作」から、矢印・A/B・Esc・すべて選択・元に戻すを押せます。移動系は指でなぞり、ウィンドウ変更は端末の縦横回転で代替できます。

追加分と既存の円の対応表、判定の詳細は [ADDITIONS.md](ADDITIONS.md) を参照してください。

## PCの操作

| 操作 | 方法 |
| --- | --- |
| 暗闇に触れる | クリック／ダブルクリック／右クリック |
| 長押し・線を描く | マウスを押し続ける／ドラッグ |
| 両手の操作 | Shiftを押しながらクリック |
| 上下に戻す | マウスホイールで上下にスクロール |
| タイトルをつかむ | 文字選択／マウス長押し。選択解除は別の場所をクリック |
| 中央に触れる | 中央のタイトル、またはその周辺をクリック |
| 別の場所から戻る | 別タブをしばらく見てから戻る |
| 再訪する | F5やCtrl+Rで再読み込み／開き直す |
| 部屋のサイズを変える | ウィンドウをリサイズ |
| 全画面 | 右上の全画面アイコン |
| 通知を扱う | 押す／ドラッグ／捕まえる。一覧からいつでも再表示可能 |

放置はページが表示され、メニューを閉じている間だけ判定します。タブを隠していた時間やメニューを読んでいた時間を放置扱いにしません。通知はしばらくすると消えます。新しい解除通知は待たずに表示中の通知の上へ並び、条件文とウィンドウの高さに合わせて表示数を調整します。各通知は個別に消え、つかんでいる間は消えません。再表示は何度でもできます。動き軽減設定と `prefers-reduced-motion` に対応し、軽減中の通知は逃げません。

## 開発用の達成方法表示

`dist/config.js` の `developmentMode: true` で、未解除の実績名と達成方法も一覧に表示します。通常の隠し実績表示へ戻すときは `false` に変更してください。設定画面に開発オプションは増やしていません。通知の短い条件文と、開発用の達成方法を分けて管理しています。

## 全画面表示

右上の四隅アイコンで切り替えます。全画面には通知やメニューを含むゲーム全体を表示します。同じアイコンで解除でき、ブラウザ側で全画面を解除した場合もボタン表示が戻ります。Escでも解除できます。全画面にできないブラウザでは没入表示になります。

## テスト

```sh
node --test tests/*.test.cjs
```

`npm test` でも同じテストを実行できます。PowerShellで `npm.ps1` の実行が制限されている場合も、上のNode.jsコマンドで検証できます。OS設定の変更は不要です。

イベントテストは小さなDOMモデル上で**本体のapp.js**を実行します。ブラウザの描画、実際のタッチ認識、ネイティブのファイル保存ダイアログまでを保証するものではありません。実画面での確認状況は [QA.md](QA.md) を参照してください。

## 保存とやり直し

キーは `nothing-is-here.v1`、保存先はlocalStorageです。IDと解除日時、累計移動距離を保存し、解除数・称号・解除率・最レア実績を集計します。ポイント制度はありません。以前の保存データに含まれる現行実績は引き継ぎ、削除済みの実績IDや不要になった設定、不正な値は除外します。JSONが壊れていれば空の状態で起動します。明るさ・明かりの実績はPC向けのショートカット操作の実績に置き換えています。

最初から遊び直すには、**設定 → 最初からやり直す → 消してやり直す** を選びます。実績・設定・操作途中の判定を初期化し、実績0個から始めます。「続ける」なら保存済みの記録を残します。ページの再読み込みだけでは実績は消えません。

## 実績を追加する

1. `core.js` の `rows` に `id / 名前 / 説明兼解除条件 / 分類 / イベント / レア度 / 非公開` を追加します。
2. `app.js` の実際の操作から `emit('イベント名')` を呼びます。PC専用機能なら必ず補助操作も接続してください。
3. 時間・順番など複合条件は `test` 判定か入力処理へ追加します。実績を定義しただけで終わらず、イベント経路を実装してください。
4. テストと解法表を更新します。総数・解除率は自動集計され、最終実績はほかの全実績の解除を待ちます。
5. 100個へ増やす際は説明文と称号の条件を調整してください。判定とUIは分離されており、実績ごとのDOMを手書きする必要はありません。

ゲームプレイ中に外部通信する処理はありません。共有ボタンを押した場合だけXの投稿画面を開きます。位置情報・カメラ・マイク・通知権限を要求しません。
